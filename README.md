# PowerCode

Welcome to **PowerCode** — a gamified programming language designed for developers who want to code like a true gaming champion! PowerCode brings the world of coding and gaming together, offering a fun, unique experience with its own custom keywords and language flow.


## Features

- **Custom Keywords**: All Python keywords are replaced with gaming-related and meme-inspired terms.
- **Fun Error and Success Messages**: Say goodbye to boring success and error messages, and enjoy memetic phrases like "Mission Accomplished!" and "Error 404: Code not found."
- **File Extension**: PowerCode files use the `.pcd` extension.
- **PowerCode Interpreter**: Translates your PowerCode into Python and runs it, while replacing keywords with their gamified equivalents.
- **Gamified Programming**: It’s like playing a game while coding!


### Prerequisites

- **PowerCode** source files use the `.pcd` file extension. 
- This interpreter has been tested in **Kali Linux**, no other Operating System have been properly tested.



### Usage

1. Write your PowerCode in a `.pcd` file. Here's an example PowerCode script:

    ```pcd
    
        showoff("Welcome to PowerCode!");
  
    ```

2. Use the PowerCode interpreter to run your script:

    ```bash
    ./pcd test.pcd
    ```
